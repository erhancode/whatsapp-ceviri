# 🌐 WhatsApp Переводчик (расширение Chrome)

[Türkçe](README.md) · [English](README.en.md) · **Русский**

**Полностью бесплатное** расширение для перевода в web.whatsapp.com. Переводит входящие сообщения прямо в чате, а ваш текст переводит на язык собеседника до отправки.

> **Бесплатно.** Нет платной версии, подписки, аккаунта и нашего сервера. С собственным API-ключом перевод заметно лучше; без ключа расширение работает на встроенном в Chrome переводе (см. [Какой движок выбрать?](#какой-движок-выбрать)).

## Что умеет

- **Входящие:** у каждого сообщения на иностранном языке появляется ссылка **🌐 Перевести**. Перевод показывается сразу под оригиналом. При включённом *автопереводе* последние ~15 сообщений переводятся сами. Страница не перезагружается, исходное сообщение не меняется.
- **Исходящие:** пишете на своём языке → Enter (или «Отправить») → открывается **предпросмотр**: можно отредактировать перевод, сменить язык или отправить оригинал. После подтверждения сообщение уходит на языке собеседника.
- **Язык собеседника** определяется по входящим сообщениям этого чата; можно задать вручную.
- Переключатель **🌐 Перевод: ВКЛ/ВЫКЛ** для каждого чата, тёмная тема, интерфейс на 25 языках.

## Какой движок выбрать?

| | Встроенный перевод Chrome | AI-модель (с API-ключом) |
|---|---|---|
| Настройка | Не нужна, работает сразу | URL + API-ключ в настройках |
| Стоимость | Бесплатно | Зависит от провайдера (у многих есть бесплатная квота) |
| Качество | Приемлемо; идиомы, тон и сленг часто передаёт плоско и «роботом» | **Заметно лучше**: сохраняются тон, вежливость, эмодзи, имена и переносы строк |
| Конфиденциальность | Текст не покидает устройство | Текст уходит только на указанный вами адрес |

Короче: **встроенный перевод Chrome не всегда переводит хорошо.** Для коротких бытовых сообщений его достаточно; для деловой переписки, официальных писем и случаев, где важен нюанс, лучше добавить API-ключ. Подходит любой OpenAI-совместимый провайдер (9router, OpenRouter, Groq, LM Studio, Ollama и др.). Если добавить несколько моделей, они пробуются по порядку: основная, затем резервные.

## Установка

Расширение **не опубликовано в Chrome Web Store**, поэтому кнопки «Установить» в один клик нет. Установка занимает около минуты:

1. Скачайте репозиторий: **Code → Download ZIP** (или `git clone https://github.com/erhancode/whatsapp-ceviri.git`).
2. Распакуйте архив в папку.
3. Откройте в Chrome `chrome://extensions`, включите **Режим разработчика** (справа вверху), нажмите **Загрузить распакованное расширение** и выберите эту папку (ту, где лежит `manifest.json`).
4. На открывшейся странице настроек выберите язык. При желании добавьте AI-модель → *Проверить* → *Сохранить*. **API-ключ нужно ввести самостоятельно** — в коде ключа нет.
5. Обновите вкладку WhatsApp Web клавишей **F5**.

Требуется Chrome **138+** (для встроенного API перевода). Если используете только AI-движок, подойдут и более старые версии.

### Можно ли установить «пакетом»?

- **Файлом `.crx`:** Chrome блокирует `.crx` из-за пределов Web Store по соображениям безопасности (разрешено только через корпоративную политику). Не рекомендуем.
- **ZIP/папкой (этот репозиторий):** шаг 3 выше — это рабочий способ. Для обновления распакуйте новый ZIP поверх той же папки и нажмите ↻ на `chrome://extensions`.
- **Chrome Web Store:** не опубликовано. Для публикации нужен аккаунт разработчика и разовый платёж.

## Настройки

- **Мой язык:** язык, на который переводятся входящие.
- **Движок:** AI с резервом Chrome / только AI / только Chrome.
- **Автоперевод:** переводить входящие без нажатия.
- **Переводить исходящие:** показывать окно предпросмотра.
- **Поведение Enter:** если в WhatsApp выбрано «Enter = новая строка», снимите соответствующий флажок — тогда предпросмотр открывается по **Ctrl+Enter**.
- Панель ⚙ справа вверху чата применяет те же настройки к отдельному чату.

## Конфиденциальность

У расширения нет своего сервера, аналитики и трекинга. Текст сообщений уходит только на указанные вами AI-адреса; при встроенном переводе Chrome текст не покидает устройство. Все настройки хранятся в `chrome.storage.local` на вашем компьютере.

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.json` | Описание Manifest V3 и разрешения |
| `wa-translate.js` | Интерфейс на странице: кнопки перевода, предпросмотр, настройки чата |
| `background.js` | Service worker: маршрутизация сообщений, резервный реальный ввод (CDP) |
| `translate-bg.js` | Запросы к AI-провайдерам и промпты |
| `options.html/css/js` | Страница настроек |

Нет сборки, `package.json` и зависимостей — обычный JavaScript.

## Известные ограничения

- Вставка текста и поиск сообщений зависят от структуры страницы WhatsApp и могут сломаться после её обновления. Строка **Диагностика** внизу панели ⚙ показывает, что найдено.
- Резервный способ ввода может на короткое время показать баннер «отладки» Chrome.
- Предпросмотр цитируемых сообщений не переводится.
